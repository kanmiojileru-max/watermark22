CCC Ijesha IV Parish Harvest Watermark App - FIXED

This is a single-file app. Upload ONLY index.html to the root of your Vercel project (or deploy this ZIP as a project through Git/CLI). No separate watermark file is needed.

For Vercel: create a GitHub repository, add index.html at repository root, then Import Project in Vercel; Framework Preset: Other; no build command; output directory left blank.

If using an existing project, replace its index.html and redeploy.

Photos are processed locally in the browser. PNG export keeps the source pixel dimensions.
